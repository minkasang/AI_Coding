**但发现两个必须修的交互缺陷**，都在你正在返工的 `workbench-v2/` 里：

### 1. 左栏装配树点选会退出 C-01 模式，且视窗空白

复现（1500×920，`?view=model`，C-01 已激活）：

| 步骤 | 标题 | `__CARLAB_C01_ACTIVE__` | 选中 |
|---|---|---|---|
| 点击前 | `C-01 静态工装` | `true` | `PI-30-006-FL` |
| 点左栏装配树「转向节本体」`[data-select="PI-20-016-FL"]` | `工程装配` | `false` | `PI-30-006-FL`（未变） |

点完之后视窗里**一个零件都没有**，只剩网格地面与坐标轴；底部 toast 还挂着
「已载入 C-01 九实例静态样板（DEMO_ASSUMPTION）」，左栏仍是 9 行 C-01 实例。
证据图：`viewer/experiments/wheel-end-workbench-qa-v1/results/shot-assembly-tree-click-after.png`。

成因在 `main.js` 的全局 click 处理器：

```js
// button.dataset.select 分支
if (c01State?.active) { void exitC01Mode().then(() => store.select(id)); return; }
```

而 `PI-20-016-FL` **只存在于左栏装配树**（车辆树 14 行里没有转向节），
所以转向节在界面上唯一能点的树行，恰好就是「会退出 C-01」的那条。
后果是转向节只能靠视窗拾取选中（这条路是通的，我验过：点模型能选中并同步到树）。

建议：`c01State.active` 时 `data-select` 分支直接走 `store.select(id)`（C-01 的 store 就是 C-01 的
`createDemoProject(seed)`），不要 `exitC01Mode()`；另外退出后视窗空白这件事本身也要兜底
——当前既没有零件也没有错误提示。

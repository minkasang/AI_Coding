# R-04｜研究悬架怎样真实运动

**一句话**：搞清楚双叉臂、麦弗逊悬架运动规律，以及哪些只是动画。

**怎么做**：从机械硬点和运动约束入手，设计可测试的行程扫描。

**了解一点**：运动学关心“怎么动”；动力学还要解释“为什么这样动”。

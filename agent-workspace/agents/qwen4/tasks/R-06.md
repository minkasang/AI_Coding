## 自主路线说明（为什么这样排）
- 任务书的成功样子是"下游知道哪些能建、哪些不能建"，不是"凑齐 N 个图纸"。所以先定**证据需求与阻塞语义**，再去检索；查不到就如实留空并阻塞，而不是先找数再凑理由。
- 复用 RP-01 已批准身份（rp01Ref）而非新建第二套零件编号，并由校验器逐个核对，避免跨模型身份漂移。
- 把"关键参数不得用演示值填""冲突参数必须保持未知""界面缺证据必须声明阻塞"写成 B05/B09/B10 三条机器规则，并用反例证明它们真会拒绝——因为文字劝告拦不住下游。
- 世界 Frame 与驱动形式仍属待裁决项，本任务只给局部 Frame 建议与条件适用标记，不单方面定案。

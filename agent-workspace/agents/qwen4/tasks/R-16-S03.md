# 自主子任务：四角、镜像与互斥架构

## 执行步骤
- [x] 建立四个角位站，带轴/侧/转向/制动/悬架拓扑/转向节有无/深度七个条件字段
- [x] 后轴显式限制：RP-01 的 ASSY-30-001 是前轮端样例，转向节不可跨拓扑复用，后角只建轮端/车轮/鼓式身份
- [x] 驱动形式全部 CONDITIONAL_UNKNOWN，继承 R-06 不擅自定案
- [x] 三类左右敏感性：MIRROR_REGENERATE(20) / SYMMETRIC_PART_DISTINCT_MOUNT(182) / SYMMETRIC_SHARED(291)，三类 globalScaleForbidden 全为 true
- [x] 37 个局部安装 Frame，按角位带 handedness，mirrorPolicy=REGENERATE_MIRRORED_GEOMETRY
- [x] CG-HUB 互斥：Gen1 必需独立法兰、禁 Gen3 件；Gen3 必需双法兰+独立内圈、禁 Gen1 法兰与螺柱
- [x] 新增候选 CG-FASTENER：STUD_AND_NUT（螺柱按代际选 + 螺母角色）/ LUG_BOLT（无螺柱 + 螺栓角色），与 CG-HUB 正交可组合
- [x] PART-30-029 按架构赋角色 WHEEL_NUT 或 LUG_BOLT，解决同一节点双角色问题
- [x] Dorman 610-460 隔离：installedInThisSkeleton/isVehicleSelection/isDemoSamplePart 三重 false，allowedUse 限 FID-V
- [x] 10 项 MODEL_BLOCKED 清单，每项带理由与 R-06 参数追溯

## 边界
CG-FASTENER 只作为骨架内候选规则；**不修改已批准的 RP-01**，改为提出补丁方案 P-01 交总控。

## 关键裁定理由
- **为什么新增选择组而不直接改根树**：RP-01 已 approved，自行修改破坏验收基线。任务书明确要求「只提出补丁方案和相应可测试证据，由总控决定」。
- **为什么互斥规则要做组合测试**：只会拒绝的规则证明不了可组合性。四种合法组合必须真正生成不同但自洽的骨架（螺柱差值正好 20=5×4），才说明规则可用。

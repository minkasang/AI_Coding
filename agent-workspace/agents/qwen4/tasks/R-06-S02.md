# 自主子任务：参数证据需求矩阵

## 执行步骤
- [x] 逐类列出关键参数、单位、坐标参考点/局部安装 Frame 建议（30 类，每类带 referencePoint；B11 强制非空）
- [x] 为每类定义可接受的证据类型与最低门槛（厂商尺寸图 > 标准条款 > 官方技术页 > 公开工程资料 > 分销商二手 > 摘要不采信）
- [x] 定义"最小验证需求"：哪些参数缺了就绝不能建模，哪些可先用明确演示假设（20 个 critical / 10 个非 critical）
- [x] 标注当前状态 SOURCED / ENGINEERING_INFERENCE / DEMO_ASSUMPTION / UNKNOWN（UNKNOWN 21 / DEMO 5 / SOURCED_SECONDARY 3 / INFERENCE 1）
- [x] 指出哪些参数属于 Grok 运动学范畴、哪些属于 Gemini CAD 范畴，避免越界（每类带 blockingDownstream 文案）
- [x] 输出矩阵供 S03 检索与 S04 JSON 直接消费

## 边界
不冻结全局 PartSpec/Frame/Joint；只提需求与建议。

## 核心立场
`critical=true` 的参数**只允许由 SOURCED / SOURCED_SECONDARY 填值**，否则必须 null + UNKNOWN。这条由校验器 B05 强制执行，反例已证明它会拒绝"把代码兜底常量 114.3 填进 PCD"。

# R-01｜研究一套底盘怎样衍生不同车型

**一句话**：研究轴距、轮距、车身等哪些可变，哪些必须保持一致。

**怎么做**：对照大众 MQB、丰田平台资料，写出合法与非法变型规则。

## 自主路线说明（为什么这样排）
- 任务书要求"不是复述汽车行业概念"，所以先做只读实测：既有研究文档已给概念层级与传播表，**缺的是可执行规则与真会拒绝的反例**，这是本轮的增量。
- 实测推翻了一个直觉猜测：摆臂不是"长度写死所以会脱开"，而是每帧 `aimSpan` 重算后 `legA.scale.z` **静默拉伸**——后果更隐蔽，任何轮距都被接受。规则必须针对这个真实行为设计。
- 阈值尽量由实测常量推导（纵梁 2860 mm → 轴距上限 2660 mm），推导规则本身标 ENGINEERING_INFERENCE，数值标 DEMO_ASSUMPTION，不冒充厂商参数。
- 世界 Frame 与零件身份仍是审核 §3 的待裁决 P0 冲突，故硬点用相对规则表达，**不替 RP-07 定案**。

## 关键裁定理由
- **为什么身份与几何分开**：混取最弱会把「结构已核实但几何未测」误报为全未知，丢失可追溯信息。分开后 124 个实例保留 SOURCED_SECONDARY 身份，同时总体仍诚实为 UNKNOWN。
- **为什么 EVIDENCE 无 sources 要降为 UNKNOWN**：不得无来源声称已核实，与总控对 R-08 的返工判定同一条纪律。

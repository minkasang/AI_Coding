# 自主子任务：两个深钻样例

## 执行步骤
- [x] 双叉臂前轮端：摆臂/球铰/衬套/转向节/轮毂轴承/制动盘/卡钳/紧固件逐层展开（`ASSY-20-001` 上/下摆臂+球铰+防尘罩+卡簧+调整垫片+转向节；`ASSY-30-001` Gen1 与 Gen3 轴承单元、车轮、轮胎；制动盘/卡钳/半轴外端/轮速传感器用 REF 指向规范身份）
- [x] 发动机：缸体缸盖/曲柄连杆/配气/正时/润滑/燃油点火/附件驱动逐层展开（`ASSY-50-001` → 曲柄机构/缸盖配气/润滑/燃油/点火/进排气/附件/起动/油门踏板，105 节点）
- [x] 每个零件标注：是否可建模、几何依据状态（有来源/需测量/纯假设）、来源 ID（geomBasis 五态 + geomNote + sources；R21 强制缺几何必须说明）
- [x] 标出轴承、密封、螺栓、卡簧、垫片等固定件与复用件身份（partClass 分类 + SYS-130 的 37 个 FAM 家族；R15/R16 强制深钻含轴承/密封/紧固件，发动机另含连杆）
- [x] 汇总"尚需取得几何依据"清单，作为下游 CAD 任务的输入（`RP-01-geometry-needs.json`，487 项，SYS-30 31 / SYS-20 88 / SYS-40 70 / SYS-50 89 / SYS-60 55）
- [x] 给出演示级简化边界（例如燃烧/传热/公差配合不在本轮）（报告 §12；轮胎分层仅示意、外购不可拆总成；曲轴组与正时驱动整块标 ASSUMPTION 并写明无一手来源）

## 边界
禁止把某品牌封闭技术参数当公开事实；不预填质量与公差数值。

## 实测结论（必须如实记录）
- **493 个零件中 SOURCED = 0**：深钻证明了"零件存在性与装配关系"，没有证明任何尺寸。
- 发动机证据强度不均：活塞连杆组与配气机构有 MAHLE/Bosch 等公开资料支撑，**曲轴组与正时驱动整块 ASSUMPTION**。
- Gen3 轮毂单元仍有独立内圈（S05），不能当单一整体件；ABS 编码环是选配。

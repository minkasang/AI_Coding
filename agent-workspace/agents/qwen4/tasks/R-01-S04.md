# 自主子任务：样例变体

## 执行步骤
- [x] 定义一个演示 PlatformFamily（固定硬点、可变范围、模块槽、接口契约），全部数值标 DEMO_ASSUMPTION（PF-DEMO-BOF-01；LOCAL_MEASUREMENT 项均带 M0x 来源）
- [x] 合法变体 A：短轴标准轮距（2460 / 1680 / 胎宽 235，RAIL-2860 + FLOOR-STD + BOF-SUV-SHELL）
- [x] 合法变体 B：长轴宽轮距（2660 / 1800 / 胎宽 255，触发传动轴重生成 2320→2520 与地板换模块 FLOOR-STD→FLOOR-LONG）
- [x] 非法变体 C：至少违反一条硬规则，并能被校验器指出具体冲突（2900 / 2200 / 轿车壳，7 类失败类型 13 条明细）
- [x] 每个变体给出预期判定与预期失败类型，作为校验器的断言输入（expected.verdict / expected.failures / derivedExpected，容差 0.15 mm，夹具失配 0）
- [x] 与 RP-01 产品树节点 ID 关联（引用 ASSY/PART 身份，不复制实体）（每个 ModuleSlot 带 rp01Ref，如 MS-FSUSP→ASSY-20-001、MS-PROPSHAFT→ASSY-60-004）

## 边界
不得声称任何数值是 OEM 参数；不写 `src/`、CAD 或共享 Schema。

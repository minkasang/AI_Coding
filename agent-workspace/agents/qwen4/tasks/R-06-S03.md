# 自主子任务：来源检索与核实

## 执行步骤
- [x] 复用 RP-01 的 82 条来源登记，筛出可能含尺寸数据的厂商/标准条目，避免重复无效抓取（筛出 S03/S04/S05/S06/S07/S10/S15/S16/S17/S19/S20/S21/S22）
- [x] 定向检索：轮毂轴承目录代号与内外径宽、轮胎规格标记与推算直径、螺栓性能等级、制动盘尺寸、减振器行程、球铰锥度（轴承与轮胎取得部分证据；螺栓/制动盘/减振器/球铰本轮 UNKNOWN）
- [x] 每条来源记录 URL + 获取日期 + 可信度 + 逐字关键数据（22 条全部带 accessedAt/retrieval/grade/license/supports/doesNotSupport）
- [x] 明确区分"目录代号编码的尺寸"与"实际装配拓扑/配合"（NSK 官方只支持代号编码原则；42/80/42 来自分销商；类型分类冲突记为 CC-01，内部几何全 UNKNOWN）
- [x] 不可达/付费/需授权来源如实标 UNKNOWN 或 OUT_OF_SCOPE（NSK PDF 不可解析、Remlagret 429、Bridgestone 403、BCcampus 403；摘要一律 usedForClaim=false）
- [x] 许可证与可复用性逐条标注（license 字段；B08 拒绝许可证不明却 usedForGeometry=true 的来源）

## 边界
不抓取未授权 OEM 图纸或付费标准全文；不无必要下载大量 STEP；缓存/临时文件一律 F 盘。

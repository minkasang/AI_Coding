# 自主子任务：范围与 BOM 骨架

## 执行步骤
- [x] 从 RP-01 已批准树提取轮端（ASSY-30-001）与双叉臂（ASSY-20-001）子树及跨系统 REF，作为唯一身份来源（另提取 ASSY-40-007 制动模块与 ASSY-20-014 转向拉杆组）
- [x] 逐件判定：机构必需 / 视觉可选 / 本轮延期，并写明理由（49 必需 / 2 功能必需延期 / 4 视觉可选 / 5 超范围延期，每项带 deferReason）
- [x] 定义总成边界与装配层级（8 个总成组；轴承与轮胎标 PURCHASED_NON_SERVICEABLE，首轮只建外形包络不建内部）
- [x] 列出必需紧固件与连接界面（螺栓/螺母/卡簧/垫片/衬套/球铰；12 个连接界面，不含具体数值）
- [x] 明确不纳入本轮的项（整车 493 件、右前/后轮、稳定杆需两角联动、Gen3、轮胎分层、转向器本体、减振器阀片、混动专用件、燃烧/传热、轮胎有限元、碰撞法规）
- [x] 输出 BOM 骨架供 S02 参数矩阵与 S04 结构化 JSON 消费

## 边界
只读 RP-01 证据与 `src/`；不修改共享树、不新建第二套零件身份。

## 关键裁定理由
- **单角**：单角即可闭合机械链；两角会引入稳定杆等跨角约束，超出首个样板。
- **Gen1 而非 Gen3**：Gen1 外形尺寸可由公开目录代号获得（d/D/B）；Gen3 双法兰几何高度车型专属、本轮几乎全 UNKNOWN。
- **驱动轮标 CONDITIONAL**：是否驱动轮属 R-01 变体决策，CV 关节与 IF-12 条件适用，不擅自定案。

# 03.49.02｜实现 C-05 转向外端血缘核验器

## 引擎功能设计
- 支持 `--metadata-only` 与 `--full-release`。
- 校验 packageId、schemaVersion、sourceGrade (`DEMO_ASSUMPTION`)。
- 校验 assets 与 sha256 字典完整性及 STEP 文件哈希一致性。
- 校验上游 C-01、C-02、C-03、C-04、快照多重指纹。
- 强制拦截非法的 partInstanceId 注入、非法的 OEM 宣称、非法的运动播放启用等。

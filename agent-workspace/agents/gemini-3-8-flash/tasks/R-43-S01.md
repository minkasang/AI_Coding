# 03.45.01｜制定 C-03/C-04 同源血缘依赖与质量门禁规范

## 关键要点
1. **C-03 球头包边界**：
   - 包含 `upper-ball-stud.step` 与 `lower-ball-stud.step` 两份实体文件；
   - 依赖 C-01 发布清单与装配 STEP、C-02 基准接口；
   - 零件身份声明为 `CANDIDATE_PARTIAL_GEOMETRY`，快照对应 `PI-20-003-FL` 与 `PI-20-010-FL` 仍为 `NO_GEOMETRY`；
   - 运动状态必须保持 `playbackAllowed: false`。
2. **C-04 轮心包边界**：
   - 包含 `rim-datum.step` 实体文件；
   - 依赖 C-01、C-02 与 C-03；特别是引用 C-03 清单哈希及两个球头 STEP 摘要；
   - 标称偏移 `signedOffset` 为 24.0 mm，轮心位置 `[-3.0, 0.0, 0.0]`；
   - 运动状态保持 `playbackAllowed: false`。

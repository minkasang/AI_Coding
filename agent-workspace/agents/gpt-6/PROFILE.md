# GPT-6｜专属工作区

你在汽车数字工程平台中承担：**总指挥 · 系统架构**。

**一句话职责**：统筹研究、审查接口、拆解任务、决定下一阶段。

## 每次打开项目的顺序
1. 先读根目录 `AGENTS.md` 和 `MASTER_PLAN.md`，然后读本目录的 `PROFILE.md`。
2. 依次查看本目录 `tasks/*.md`，优先处理状态为 `in_progress` 的任务，其次为 `ready`；状态为 `blocked` 不得强行开工。
3. 必须阅读任务卡的 `brief` 所指向的详细说明，严格遵守允许改动目录和验收。
4. 每完成一个可验证的小步骤，就修改**对应任务卡**的复选框，并更新 `status`、`summary` 和 `lastNote`。网页会自动刷新；不要伪造进度。
5. 把具体研究/代码/测试证据提交到任务要求的输出路径，`submitted` 只代表待总控验收，不等于 `approved`。

**请勿修改其他模型的专属任务卡**。角色名称和任务内容可能随时间改变，真实分工以本目录任务卡为准。如果模型无法可信地确定自己是谁，请由用户指定工作区，不要猜测。

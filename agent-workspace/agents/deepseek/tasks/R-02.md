# R-02｜制定零件和装配的统一数据标准

**一句话**：让不同 AI 做出的螺栓、轮毂、悬架能按同一规则装配。

**怎么做**：设计零件编号、安装点、关节、坐标和版本的统一数据结构。

**了解一点**：Schema：像零件的产品说明书，规定字段和正确的连接方式。

## 执行步骤
- [x] 核对 RP-01/RP-02/R-01 现有字段、真实 ID 与审计 P0 冲突
- [x] 定义 PartFamily/PartDefinition/PartVariant/PartInstance/Assembly/Joint/Material/VehicleVariant 身份、版本和生命周期（S01）
- [x] 定义 Frame、mm/m、局部/世界坐标、左右镜像与 mount hardpoint（S02）
- [x] 定义运动副中性抽象、STEP/STL/GLB manifest 与实例复用规则（S03）
- [x] 生成 BOM→法兰→5 螺栓→制动盘示例 JSON，使用 RP-01 真实 ID（S04）
- [x] 实现并运行至少 12 个校验案例、3 个刻意错误 JSON、记录 PASS/FAIL（S04）
- [x] 写报告、列 R-01 待对齐点与 CAD B-rep 检查边界，提交待审

## 子任务
- `R-02-S01` 实体身份、版本、生命周期与 ID 规则
- `R-02-S02` Frame、单位、坐标、镜像与安装接口
- `R-02-S03` 运动副抽象、资产映射与实例复用
- `R-02-S04` 示例装配 JSON、校验器、测试与报告

# C-02｜左前轮端 CAD 基准交付

[机读基准表](../../../../cad/experiments/wheel-end-datum-interface-v1/datums.json) 从 C-01 已验收发布包提取七个基准，包含上下锥口、轴承座外端与内肩、轴承外圈两端面、轮毂车轮安装面。按 R-27 的实例身份定位。每行提供物理特征、零件及工装的 Frame 矩阵、米制 GLB 位置和单位方向，共用 `DEMO_ASSUMPTION` 来源等级。

## 实测

- Python 提取器两次实跑，生成 JSON 后以 `--check` 重算一致。两套 STEP 共核对 14 处实体特征，锥口额外核对锥面大小端。
- Node 用实际 GLTFLoader 核对七个基准和四组独立固定算例。最大点坐标误差为 `3.7997961e-10 m`，单位向量误差为 0。这是坐标与变换的数值复算误差。
- 四项注入均拒绝。把锥口的毫米坐标写入米字段，尝试发布播放状态，篡改锚点平移，以及用 STEP 冒充应有哈希的 GLB。
- R-28 中位帧 2 的上下球心和轮心角色标记反算与原运动夹具一致，最大数值差 `8.77e-14 m`。采用向外的主轴单位向量与从下到上的顺序后，C-01 锥口差的主轴投影为 0 mm，R-28 球心差为 −79.3776009561 mm。即使仅沿各锥孔轴补球心偏移，CAD 投影仍保持零。

## 消费边界

C-01 安装锚点的 Z 轴是工装根的 +X，工装根的 +Z 依旧向上。请读取 JSON 中分别表示这两种坐标的 `frames.anchor` 和 `frames.workholding`。手性、单位、输入 SHA-256 和 R-28 运行身份均包含在证据中。球心、轴承端面到下球心、轮毂安装面到轮心、外拉杆接口和共同物理点关系仍缺证据，保持 `REGISTRATION_BLOCKED`。

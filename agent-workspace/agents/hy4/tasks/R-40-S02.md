# 03.42.02｜双尺寸截图与零件辨识

## 为什么不用「选中前后逐像素差分」

选中零件会触发 `viewport.focus(partId)` 移动相机，两帧不是同一投影；差分测到的是整体位移，
首版曾出现掩码覆盖 60% 画布、Δ 亮度 +80。改走两条独立路径：

1. **逐件颜色**：用页面自带「隔离选中零件」单独渲染，再按色度分类取像素；
2. **整体可见性**：树点选产生高亮 → 与无选中基帧差分得到轮廓 → 在**未高亮的原图**上
   按腐蚀后的遮罩取色（真实共视条件）。

## 取色规则（`partColor`）

限定模型区（y ∈ [60, h−110]）→ 排除背景 `#eef3f8` ±6 → `chroma ≥ 12` → 要求 `b>g>r` → 排除 `L>232`。

## 判空规则

隔离视图模型区零件像素 `<3000` 视为隔离为空，不给颜色结论，只记 `rawPixelsInModelArea`。

## 结果

**布局**：1500×920 与 1280×800 均 0 处重叠、无横向溢出、选中前后画布 Δw=Δh=0。

**整体可见性**

| 零件 | 轮廓像素 | 占画布 |
|---|---|---|
| 转向节 | 11934 | 2.35% |
| 轮毂法兰 | 19704 | 3.88% |
| 螺柱（单实例） | 580 | 0.11% |
| 轴承外圈 / 内圈 | 0 / 0 | 0% |

**隔离测色**：转向节 181.18、轮毂 197.91、螺柱 194.91、外圈 199.84、内圈 208.03（极差 26.85）。

**拾取**：3×3 网格命中 3/9（转向节、螺柱 03、螺柱 04），命中后与树同步 3/3，不一致 0。

# R-05-S02｜质量问题归因审计表与机械材料视觉标准

## 实际结果（真实完成）

- **12 条质量审计项**，每条含：现象 → 源码位置 → 可观察表现 → 归因 → 改进顺序 → 证据等级。主因按影响排序：
  1. **辐条与轮辋硬边**：`src/parts/wheelRim.js:6-18` 的 `TriSoup` 为非索引三角汤 + `computeVertexNormals()`，得到面法线硬边；`buildHubData` 的 `bevelSize/Thickness = 0.002 m`、`bevelSegments = 2`（`:104-111`）。在约 0.68 m 外径的轮毂上，2 mm 倒角于 1600 px 帧内仅约 1–2 px，几乎不产生高光滚边。特写帧中辐条呈平薄锐边深色片。
  2. **环境反射内容单一**：`src/main.js:54-55` 的 `RoomEnvironment` 是程序化白盒，金属反射的是白墙与灯板；为补偿而把 `envMapIntensity` 推到 1.3–2.1（`tire.js:349-365`），结果是亮但无高频细节，像镀铬塑料。
  3. **接触阴影失真**：`src/main.js:144-149` 的 `aoGeo/aoMat` 是径向渐变 `CanvasTexture` 贴片，仅用于 `tireStage`；整车模式完全没有。真实阴影依赖单一 `DirectionalLight`，shadow camera ±9 m 配 2048²（约 8.8 mm/texel）+ `shadow.radius=3`，再被 `HemisphereLight 0.58` 与 IBL 填平。两帧基线里轮下只见模糊灰影，物体"浮"在背景上。
  4. **材质无空间变化**：全场景 `normalMap/roughnessMap/aoMap` 零命中；仅 4 张程序化 CanvasTexture（胎侧 1024²、刹车盘 512²、中心盖 256²、展台 AO 256²）。大面积金属是常数 color+roughness+metalness。
  5. **构图与背景**：纯色 `0xf2f0ec` 背景与 `0xeae7e1` 地面近似、`Fog(18,52)` 在常用相机距离下几乎不生效；整车帧四周大面积留白，主体占比小，细节被 UI 面板挤压。
  6. **色彩语义**：橙红弹簧/卡钳是唯一高饱和色，与灰黑车架形成玩具配色；无渐变背景或地面反射。
  7. 其余：无后处理（SSAO/GTAO/contact shadow/bloom 均缺）；`exposure` 与 `environmentIntensity` 只有全局滑块（`:748-751`）；胎侧字标与中心盖 logo 为 Canvas 绘制，放大后分辨率不足。
- **7 类材料视觉标准**（锻造/铸铝、钢制刹车盘、橡胶、塑料、镀铬、油液）：逐类给出 metalness / roughness 建议区间、需要真实几何的细节（倒角、钻孔、通风槽、胎纹块、字标浮雕）与可用 normal/roughness 贴图替代的细节（铸造砂眼、车削纹、橡胶微纹、油膜）；明确"建议待 A/B 实测，不是已验证参数"。
- **明确不声称**：没有把"WebGL 质量低""缺 HDRI"当作原因；现有 PBR 链路已完整，问题在内容与几何细节。上述观感判断来自 SwiftShader 软件渲染帧，标为 `DERIVATION`，需 S03 的 A/B 在真实 GPU 上复核。

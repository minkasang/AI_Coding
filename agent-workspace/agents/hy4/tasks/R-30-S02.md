# 03.32.02｜受控 M 单变量 adapter

## 设计约束
- **默认关**：`enabled=false` 时 adapter 不写任何材质字段，生产行为完全不变。
- **一键回退**：`disable()` 无条件写 `LEGACY_PBR = {0.70, 0.34, 1.05}`，与 `viewport.js:166-167` 一致；不依赖进入时快照。
- **幂等**：`setEnabled(true)` 重复调用不叠加；`on→off→on` 后 snapshot 与首次 on 逐字节相同。
- **reapply**：`viewport.sync()` 会给新增零件写旧值，adapter 需在 sync 后重新应用，避免混合态。
- **不碰非 PBR**：`color / emissive / emissiveIntensity / visible / clippingPlanes` 一律不写。

## 实现要点

```js
export const LEGACY_PBR = Object.freeze({ metalness: 0.70, roughness: 0.34, envMapIntensity: 1.05 });
export const LEGACY_SOURCE = 'workbench-v2/viewport.js:166-167';
export const DEFAULT_ENABLED = false;
```

`_writeLegacy()` 无条件写三个常量并清空 `missingTargets`；`_writeNative()` 从 `view.templates`
读到的 GLB 原生分档按 `partKey` 写入，找不到的零件退化为 `LEGACY_PBR` 并记入 `missingTargets`。

`setEnabled()` 先比对当前态，相同则直接返回（幂等）；`reapply()` 按当前态无条件重放一次，
供 `sync()` 末尾调用。

`status()` 暴露 `enabled / defaultEnabled / switches / appliedMaterials / legacy / legacySource /
nativeParts / missingTargets / rollback / fileLock`，审计时不必读代码。

# 03.42.01｜冻结环境与路径

## 激活链路（正常路径）

```
goto ?view=model
→ __CARLAB_V2_READY__            （工作台初始化完成）
→ __CARLAB_VEHICLE_SNAPSHOT__    （车辆快照送达）
→ __CARLAB_C01_READY__           （ensureC01Assets 通过 verified && binding && seed）
→ 点 [data-tree-toggle="SYS-30"] → 等 [data-tree-toggle="AI-30-002-FL"] 出现
→ 点 [data-tree-toggle="AI-30-002-FL"] → 等 [data-vehicle-select="PI-30-006-FL"] 出现
→ 点该行 → __CARLAB_C01_ACTIVE__ = true
```

## 两棵树的权限差别（本轮最重要的环境事实）

| 树 | 选择器 | 行数 | C-01 模式下点选 |
|---|---|---|---|
| 左栏「可编辑装配」 | `[data-select]` | 9 | **会退出 C-01 模式**且选中不变、视窗空白 |
| 车辆树 | `[data-vehicle-select]` | 14（13 行标「无几何」） | 安全，选中跟随 |

转向节 `PI-20-016-FL` 只存在于左栏装配树 → 转向节没有可用的树入口。

## 两种尺寸

1500×920（画布 876×579.6）、1280×800（画布 748×475.4），`deviceScaleFactor=1`。

# 03.42.03｜基线对照、归因与交接

## 与 R-35 基线对照

| 零件 | R-35 基线 | 本轮实测 | Δ |
|---|---|---|---|
| 转向节 | 170.3（full） | 181.18（隔离） | +10.9 |
| 轮毂法兰 | 196.5（full） | 197.91（隔离） | +1.4 |
| 螺柱 | 185.9（full） | 194.91（隔离） | +9.0 |
| 轴承外圈 | 192.3（隔离） | 199.84（隔离） | +7.5 |
| 轴承内圈 | 212.3（隔离） | 208.03（隔离） | −4.3 |

## 归因

1. 三项系统性偏亮 +7.5~+10.9，方向与量级一致 → 两套 harness 的机位/光照差异，非材质退化。
2. 内外圈差值 20.0 → 8.2：R-35 的轴承机位几乎正对内圈；页面隔离机位由 `focus()` 的固定方向
   `[0.92,0.78,1.12]` 决定，内圈多处于掠射角，金属高光被压低。色比偏差仅 −0.016/+0.037，颜色没变。
3. **可迁移的是结构性结论**：轴承在整体视图 0 像素、须用隔离或剖切验收——本轮两条均复现。
   **不可迁移的是绝对亮度值。**

## 断言清单（61 项，9 组）

1. 环境与激活（9）：5173 路径、SwiftShader 标注、C-01 激活、标题、说明、静态演示标识、树行数、清空失败 0
2. 两种尺寸布局（11）：尺寸命中、无重叠、无横向溢出、选中零挤压、画面内容量、亮度区间、零跳变
3. 整体可见性（6）：转向节/轮毂/螺柱可见、轴承 0 像素、差分同尺寸
4. 颜色同源（13）：5 件选中成功、无空隔离、选中路径、逐件色比 ≤0.06、极差 >15、无兜底色、序列同向
5. 选中与拾取（5）：网格 9 点、命中 ≥1、不一致 0、命中集合、陈旧残留已登记
6. 剖切（7）：model 下未生效且零变化、占比不变、inspect 下 mode/按下态、面积 −65%、两帧稳定
7. 装配树副作用（4）：行存在、点击前激活、点击后退出、选中不跟随
8. 车辆树标注（2）：13/14 标「无几何」、其中 4 类实际有几何
9. 复跑确定性（3）：repeat 标记、逐字段一致、关键证据块逐项一致

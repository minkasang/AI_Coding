## 自主执行路线（2026-11-15 16:40 制定）

### 一手发现（决定实验变量）

1. **GLB 自带材质分层被 V2 抹平**（`EVIDENCE`）：
   `wheel_hub_assembly.glb` 内 `Mat_Part_Bearing = metalness 0.95 / roughness 0.12`、
   `Mat_Part_Hub = 0.85 / 0.25`、`Mat_Part_WheelStuds = 0.80 / 0.50`；
   但 `workbench-v2/viewport.js:163-170` 在 `sync()` 里把每个 mesh 强制覆盖成统一的
   `metalness 0.70 / roughness 0.34 / envMapIntensity 1.05`。这是「视觉层次差」的直接来源，
   而恢复 GLB 原值比凭空编造材质数值更有依据、补丁更小。
2. **地面与模型之间有 54 mm 空隙**（`EVIDENCE`）：GLB `POSITION` 包围盒 y ∈ `[-0.042, 0.045] m`，
   而 `viewport.js` 的 grid 在 `-0.095 m`、ShadowMaterial 地面在 `-0.096 m`。
   叠加 `HemisphereLight 0.9` + `fill 0.9` + `exposure 1.18`，阴影既淡又离体，对应「接地太浅」。
3. **过曝**：曝光 1.18 + 半球光 0.9 + 主光 2.0 + 补光 0.9 + `envMapIntensity 1.05`。

### 实验设计

- **2×2 全因子**，四组共用 V2 同一 GLB、同一物理尺寸、同一组固定机位：
  - **M（严格单变量 · 材质层次）**：`m0` = V2 当前统一覆盖值；`m1` = 按 partKey 恢复 GLB 自带的
    pbrMetallicRoughness 数值。**只改材质数值**，颜色仍用 fixture 的 DEMO 色；全部标 `VISUAL_ASSUMPTION`。
  - **L（配置包 · 光与接地）**：`l0` = 逐参数复刻 `viewport.js`；`l1` = 一组明确列出的参数补丁
    （曝光/半球光/主光/补光/ShadowMaterial 颜色与不透明度/地面对齐到模型最低点）。
    **诚实声明：L 是多参数配置包，不是单变量**，其内部各参数贡献本轮不分离。
- **3 个固定视角**：`iso`（V2 focus 方向）、`top`（法兰盘面与 PCD 孔）、`side`（厚度与接地空隙）→ 4×3 = 12 帧。
- **观测指标**：`renderer.info`、模型 ROI 的均值/标准差/过曝像素比/边缘梯度、接地接触带亮度剖面、
  三个零件各自 ROI 的平均亮度（层次代理）、GLB mesh/三角数/材质来源。
- **反例回归**：非法 `l`/`m` 值、非米制单位、缺失 GLB 必须显式报错，不能静默回退到基线。
- **可合入产物**：`patch-candidate.json`，逐项给出 `viewport.js` 行号、`baseline → proposed`、证据等级与指标依据。

# R-05｜研究怎样让汽车机械渲染更有质感

**一句话**：分析为什么轮毂显得粗糙，设计能验证的画质升级方案。

**怎么做**：拆开比较几何倒角、金属材质、摄影棚灯光与阴影的影响。

**了解一点**：PBR：通过金属度、粗糙度和光照，让材料像真实金属或橡胶。

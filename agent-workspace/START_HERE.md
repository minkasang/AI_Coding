# CARLAB｜唯一启动入口

> 只有一件需要项目所有者做的事：打开对应主 AI 的**项目对话**（确保能访问 `F:\project\cyq\AI_Coding\car`），发一句 **「继续 CARLAB」**。

所有主 AI 都应自动按下述顺序处理；不要再要求用户选择、复制或转发每个子任务。

1. 自行阅读根目录 `AGENTS.md`，确定当前模型对应的工作位 `roleId`。
2. 读取 `agent-workspace/agents/<roleId>/PROFILE.md` 和所有主任务卡，优先继续 `in_progress`，再处理 `needs_work`，随后认领优先级最高且前置条件满足的 `ready`。
3. 读取任务 `brief` 指向的详细目标与质量标准，按需创建/复用自己的子任务和子代理。没有子代理工具则在当前主会话完成。
4. 检查 `agent-workspace/shared/messages/` 中发给自己及 `all` 的新留言，解决依赖或新建消息回复。
5. 在本人任务卡和报告里记录真实进展、证据、测试与文件路径；完成后标 `submitted` 等待 GPT-6 审核，绝不自行批准。
6. **如果目前没有待做任务、全在待审或被真正依赖阻塞**，将状态如实写回项目文件并停止，而不是让用户反复派发子任务。

GPT-6 总控的“继续 CARLAB”意味着：检查**所有模型**最新父任务、公共消息、提交物和证据；可复测的独立审核并写回结果；处理跨模型冲突；给已完成且有合适后续工作的模型创建新父任务；必要时形成公共决策消息。

### 当模型启动时所在目录不是项目目录

你仍然只需发同一条（包含路径的）统一指令：

> 在 F:\project\cyq\AI_Coding\car 继续 CARLAB，先读 AGENTS.md，然后自动领取并执行你对应的任务，直接在共享文件里交流和提交成果。

这个入口**不会自行唤醒外部 AI**。工作模型必须真的已打开、并具备项目读写权限。

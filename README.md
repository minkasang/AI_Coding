# AI Coding 工作区与 CARLAB

本仓库在 `AI_Coding` 工作区内放在 `car/`。CARLAB 的源代码、任务卡、审核与决策均随本仓库迁移。

- [总控交接提示词](docs/command/CONTROLLER_HANDOFF_PROMPT.md)可复制进新会话，供 Codex、Grok 或其他 AI 接任。
- [Mac 迁移交接](docs/command/AI_CODING_MAC_MIGRATION.md)包含恢复步骤、工程现状和首次接管检查。
- [工作位与会话路由](agent-workspace/WORKSTATION_ROUTES.md)记录 IDE、模型、对话和任务工作位的对应关系。
- [CARLAB 启动入口](agent-workspace/START_HERE.md)供执行会话使用。

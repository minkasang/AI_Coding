# C-02 左前轮端 CAD 基准接口

`datums.json` 从已验收的 C-01 发布包 `c01-c5d74da77c293aa5321f` 提取七个基准。每个基准使用 R-27 的 `partInstanceId`、对应定义和该定义的安装名。该包使用 `DEMO_ASSUMPTION`。

## 复算

在 `car` 仓库根目录运行。使用现有 Python 3.13、build123d、Node 和 Three.js。发布包缺失时按 [C-01 重建说明](../../../docs/research/C-01-wheel-end-pipeline.md) 取得被本接口引用的版本。

```powershell
$c02 = "cad/experiments/wheel-end-datum-interface-v1"
$env:PYTHONDONTWRITEBYTECODE = "1"
& ./.venv/Scripts/python.exe "$c02/extract_datums.py" --check "$c02/datums.json"
node "$c02/check-glb.mjs"
```

重新写出 JSON 使用 `extract_datums.py --out "$c02/datums.json"`。异地复制的同版发布包可用 `--package` 指定。提取器校验实际 C-01 清单、所用 STEP 及 R-27 快照哈希；GLTFLoader 检查器另验 GLB 哈希并加载实际场景。若使用异地包，Node 参数依次是 datum JSON 和 GLB 路径。基准 JSON 还记录 R-28 和运动夹具的源文件哈希、修订、运行 ID 及中位帧校核。

## 工装坐标与测量

`FR-C01-WHEEL-END-FL` 是右手工装根，轴为 +X 外侧、+Y 后、+Z 上。原点是轴承座外端面与主轴交点。`assembly.json.root.xAxis` 和 `zAxis` 分别是安装锚点局部 X、Z 轴在工装根下的坐标。锚点 z 轴为根 +X，正好沿主轴。锚点和工装根坐标使用不同字段。`rootFromAnchorCad` 用锚点向量重建，并和 `rootFromPartCad × partFromMountCad` 对照。

矩阵按行存储，乘列向量。转向节局部坐标 `(x,y,z)` 进入根为 `(z,x,y)`。GLB 换基取 `(X,Z,-Y)`，点坐标另乘 0.001 转成米。单位方向仅旋转。两次旋转的行列式均为 +1。轮毂的局部变换另含 8 mm 工装根外侧平移。

| 物理基准 | 零件局部点 mm | 工装根点 mm | GLB 点 m | GLB 轴向 |
| --- | --- | --- | --- | --- |
| 转向节上锥孔大端 | (9, 110, −21) | (−21, 9, 110) | (−0.021, 0.110, −0.009) | +Y |
| 转向节下锥孔大端 | (−8, −100, −21) | (−21, −8, −100) | (−0.021, −0.100, 0.008) | −Y |
| 轴承座内肩 | (0, 0, −42) | (−42, 0, 0) | (−0.042, 0, 0) | +X |
| 轮毂车轮安装面 | (0, 0, 13) | (21, 0, 0) | (0.021, 0, 0) | +X |

STEP 检查使用实际圆边的中心、直径和轴线。端面要求圆边位于相应平面，下锥口与上锥口用同一锥面的大小端圆边验证轴向和锥度。C-01 刀具多切 0.1 mm，因此锥面实际裁切深度从 STEP 读取，与名义凸台厚度分别理解。两个端面 Frame 的 +Z 均按主轴向外定向，字段描述的是安装轴的方向。GLB 检查同时核对全部七个 datum 和上表四个独立固定算例。

## 配准边界

R-28 零行程的转向节原点是下球心，转向节局部 X 沿下球心至上球心，轮心仍为角色标记。C-01 的锥口中心距为 210.687 mm，R-28 的两球心距为 250.200 mm。以主轴向外为正、下到上为顺序，CAD 两锥口差的轴向投影为 0 mm，R-28 球心差为 −79.3776 mm。两锥轴对主轴的投影均为零，因此仅沿各自锥轴补球心偏移不会改变结果。

消费端可用 `frames.anchor` 修正锚点轴的解释。`registration.status` 仍为 `REGISTRATION_BLOCKED`，`vehicleFromWorkholding=null`，统计差值无需拟合变换即可复验。

## 最小同源 DEMO 夹具建议

1. **静态校核夹具。** 让 CAD 和运动端记录同一版转向节的三个非共线实体特征。可复用上/下锥口与轴承座外端面的 datum ID。目标端从同一刚体上给出刚性放置后的独立点坐标，并增加可追溯的同体定向标记 `clockingWitness`，优先选有明显离面分量的物理方向或第四点，供镜像与额外残差校核。这个阶段验证基准变换，锥口仍作为座口特征。
2. **CAD 侧补齐运动几何。** 为转向节建立有装入关系的上下球头，输出每个锥口到实际球心的三维偏移和相应关节实例。以轮胎或轮辋装配定义记录轮毂安装面到轮心的偏移。若要用完整 SLA/转向运动，再提供转向臂与外拉杆端的几何基准和物理身份。脱离真实尺寸来源时，上述新值仍标 `DEMO_ASSUMPTION`。
3. **运动侧建立单独的同源 DEMO 运行。** 从这一 CAD 修订读取球心、主轴、轮心及需要的外端连接点，发布下球心和同名定向点或轴。车身侧上下摆臂枢轴、外拉杆的内端和驱动行程由运动夹具定义，按来源标记假设。使用新运行标识和输入哈希固定版本，检查独立见证点、行程中的刚性距离和闭合残差。在静态配准与运动闭合都通过后再审核播放范围。

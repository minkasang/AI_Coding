## 3. 已确认的四个新风险

1. **可信尺寸仍不足**：Qwen4 R-06 中 17/20 关键参数 UNKNOWN，12/12 装配界面阻塞。尤其 PCD/CB/ET、球铰锥度、轴承配合公差与悬架硬点没有符合工程门槛的厂商尺寸图，不能填成既成事实。
2. **零件代际/身份/归属冲突**：Qwen4 公共留言指出 R-03 `SYS-*` 到 RP-01 `PART/ASSY-*` 的 5 个候选别名需要 `applicableWhen`（例如仅 Gen1）与 `evidenceInherited`，否则会把不同代际轴承同时装车，并把 ASSUMPTION 错认成证实。
3. **静态规则与求解器错误码语义不能混淆**：`KIN-E-CONVERGE`（算法不收敛）不能直接等同 `R-01 P09`（静态不可解），`KIN-E-LENGTH` 按原因可能分流到 P08 或 P09。由 RP-07 统筹并引导 DeepSeek/Grok 隔离验证。
4. **画质诊断未等于画质改好**：HY4 R-05 提出合理方向，但没有真实 GPU 性能对照。当前 5173 工坊的改版属于独立的 UI 视觉整合，不能冒充轮毂 CAD 精度或反射模型全面升级。

# CARLAB｜统一入口与工作台业务结构（2026-11-15）

> **正式用户入口只有两个：5173 车辆工程工作台、5174 AI 任务指挥中心。**
> 这份文档取代过去把整车/轮胎/悬架/传动/装配平铺成大菜单或另开 5175 的旧运行约定。其他 AI 按此约定继续执行自己现有任务，无需用户手工转发。

## 一、运行入口

| 用户目的 | 唯一常驻地址 | 服务 |
|---|---|---|
| 查看车辆、编辑零件、观察装配、做驾驶/物理演示 | **http://localhost:5173/** | 根目录 `npm start`；自动进入 `workbench-v2/index.html` |
| 查看全部代理任务、最新提交、审核与协调 | **http://localhost:5174/#dispatch** | 根目录 `npm run dashboard` |

**不再启用第三个服务 5175**：`npm run viewer:engineering` 现在只输出 5173 内部查看器的正确地址，不再启动服务器。旧专用服务源文件未删除，历史实验可通过 `http://localhost:5173/viewer/experiments/engineering-viewer/index.html` 直接访问，但此路径不进入用户主导航。旧独立汽车站点保留为 `http://localhost:5173/legacy.html`，只由新工作台内的试验区嵌入；**不要把两者称作两辆已经物理装配在一起的车**。用户无需访问这些内部路径。

关闭 5175 只停止其 Node 进程及相关 npm 启动包装，不清理其它 AI 的 CAD、历史报告、3D 资产或源码。其它 AI 不可自动重开常驻 5175 或另增新的常驻 HTTP 端口。

## 二、业务组织（系统设计约定）

- **工程模型（model）**：选择工程、模型树和装配实例，添加/修改零件，保存/导入/导出、撤销/重做。工程操作归入同一个可展开菜单，而不是横着放很多工具。
- **展示与检查（inspect）**：**复用前一业务的同一个 ProjectStore/工程实例/GLB 视窗**，允许选中、聚焦、高亮、隐藏、隔离、爆炸查看及查看尺寸、来源。这里默认隐藏添加零件的目录和删除功能，避免把查看当编辑。
- **试验仿真（experiment）**：目前嵌入原有 Cannon-es 简化四轮车和驾驶交互，默认收起高级参数，只在需要时点「参数与控制」。旧轮胎/悬架/传动为历史独立实验样例，收在一个选择器里，不能称为同一辆车的真实机械子系统。
- **工程项目（projects）**：由左上面包屑/工程名进入的资源选择页面，不作为平级业务导航；明确区分可编辑轮端示例、独立低保真驾驶示例与创建空白工程。

**汽车物理对象树 ≠ 产品业务菜单。** 轮胎、轮毂、传动、悬架、制动、螺丝都应位于车辆对象树中；若用户需要高亮某个系统，属于**展示与检查**对所选对象执行的操作；若研究冲击/约束，属于**试验仿真**对已验证工程模型运行的工况，不需为每个零件/系统创建首页目录。

## 三、当前代码与工程事实

`workbench-v2/project-store.mjs` 负责 DEMO 项目数据，`viewport.js` 负责只读渲染适配，`main.js` 协调 UI 操作，`shell-router.js` 管理上述三类业务入口和资源页。旧驾驶场景在 `legacy.html` 引入 `src/main.js` 和简化 Cannon-es 车辆状态，**目前尚不是同一辆真实装配工程车**。此版本可证明页面入口和状态流程有效，不可声称真实多体动力学、装配干涉、OEM 尺寸和完整车辆 CAD 已完成。

根目录 `index.html` 是自动跳转到工作台的唯一入口，不再承载另一套物理/机械页面；旧源码保留以供回归。5175 也不再是任何常驻工作站的必要依赖。未来将旧试验与 `ProjectStore` 真正融合，须等待 RP-07 对真实 PartInstance/Frame/Joint/Constraint/SimulationRun 的接口裁决。

## 五、未来 UI / 功能验收规则

1. **先决定是对象、操作还是试验工况**：对象出现在零件树；操作放在具体上下文工具区；实验工况在仿真业务内部管理；只有确有新业务时才增加顶层入口。
2. 每个按钮要有真实动作和明确状态转换，否则不显示；当前尚无机械求解器，不显示无效「运行仿真」按钮。
3. 只在需要时提供相关参数；其它参数折叠/隐藏，且必须说明当前选择作用于哪辆车或哪个零件。
4. 不能为一个轮毂/悬架/方向机单独再开服务或永久顶层主导航。
5. 若改变业务结构、共享工程状态或场景，必须补真实 Chrome 点击测试，保留同源 5173/5174 两服务约定。

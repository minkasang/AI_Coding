# R-37｜核对左前上下球铰身份与运动用途

## 目标

为 C-03 新的两个演示球头核对现有零件身份，明确完整球铰、简化球头、转向节锥口和运动球心之间的关系，供运动端使用同一物理基准。

## 交付与验收

1. 从实际 R-27 快照和 R-26 候选核对上、下球铰的候选 PI、定义、父级、左右角位、Frame 和数量。单独说明球铰关联的保护件、紧固件和锥口基准，保持各自归属。区分可确认的身份与仍待验证的车型、几何和关节关系。
2. 给出带证据引用的候选表与验证命令，至少用上、下互换、错误角位，以及把运动点当作新增实体实例三个反例验证。现有轮毂角色和外拉杆延期规则继续保留。
3. 只写本工作位报告、独立验证文件和公共交接。共享快照、OEM 来源和生产接口由总控统一审核。交付给 C-03 和 Grok，完成后提交。

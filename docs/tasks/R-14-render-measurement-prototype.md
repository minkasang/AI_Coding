# R-14｜把“感觉很假”变成可测量的画质对照实验（HY4）

**背景**：R-05 已验收研究报告，证明 WebGL 并非画质差的根因；优先级更高的是轮辋法线、几何圆角、接地阴影、材质与轮胎细节，且目前没有真实 GPU 的硬件 FPS / draw call 对照。用户已将 Composer 查看器整合进明亮的 5173「小车工程工坊」，但模型本身尚不够真实。

**目标**：建立能反复运行的**隔离渲染对照样板和观测工具**，选择最能影响金属轮毂质感的 1–2 类问题做“现状 vs 改进”可验证试验。重点是有可靠证据的几何/材质/接地质量变化，而不是又给 UI 换一套颜色。

**要求**： 
- 避免在没有真实 GPU 测量的情况下声称提升了多少 FPS；可用浏览器 `renderer.info` 和固定机位截图做可观测指标，不把 SwiftShader 当真实显卡性能。
- 如使用 CC0 素材，先记录出处、确切许可证和文件哈希；没有必要就不下载 HDRI/纹理，也不要污染 C 盘。
- 同一零件相机/曝光/尺度条件下提供对比；标注哪些来自假设材质、哪些确有厂家来源，不冒充真实制动盘材料参数。
- 为避免覆盖其它模型工作，只在 `viewer/experiments/render-quality-v1/` 或 `src-experiments/render-quality-v1/` 做新实验；生产页面 5173 暂不擅改，需要集成时写公共消息给总控/Composer。

**成果**：`docs/research/R-14-render-prototype.md`、可运行试验代码/数据/说明、小型 A/B 结果与真实限制、本人 `agent-workspace/agents/hy4/reports/R-14.md`。由 HY4 自主决定技术路线和子任务；完成标 submitted 等总控审验。

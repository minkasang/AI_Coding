# R-18｜让悬架“解算后零件真的跟着动”的第一条闭环（Grok）

> 工作位：grok，P0；复用已验收 R-09/R-13 求解器。**重点是刚性零件位置、连接约束与连续运动，不是再做轮子上下浮动动画。**

## 目标
在 `src-experiments/mechanism-vertical-slice-v1/` 独立实现从“轮端约束描述 → 行程输入 → 多个时间样本的 PartInstance 位姿 → 约束残差与碰撞/间隙说明”的**可重算纵切原型**。项目最终会映射到 V2 同一车辆工程模型，但本轮**不直接写生产 Three.js/物理**。

## 必须解决
1. 对“双叉臂 + 转向节 + 轮毂 + 连杆/球铰”建立显式候选 Joint 与局部 Frame。原始摆臂长度恒定（刚性件不能通过 `scale.z` 拉伸模拟运动），挂点关系与解算位姿需可测可复核。
2. 输出至少三个行程位姿和连续采样（允许虚构硬点且必须标 `DEMO_ASSUMPTION`），记录每个实例对应的位置/四元数、角度或拉杆长度误差、求解状态及残差；物理输入无证据时不能输出“真实轮端受力”。
3. 对欠约束、过约束/硬点冲突、不收敛分别输出可读结果。对零件干涉与间隙首先用已声明的碰撞代理或包围体，不虚构已完成真实 CAD 复杂连续碰撞。
4. 继续区分 R-13 的 P08/P09/P14 静态变型失败与 `KIN-E-LENGTH/CONVERGE`，并留接口供 DeepSeek R-17 的 Instance/Frame 接入；不能自行冻结正式错误码。
5. 提供一段可在**既有 5173 站点内部**复现的结果 JSON 或检查脚本；不要另建正式网页端口/首页导航。如果要可视预览，做孤立内部样例，给总控结果截图与样本数据。

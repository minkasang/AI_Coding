# R-23｜将解算位姿转换为稳定部件实例的连续运动流（Grok）

> 前置 R-18 刚性运动纵切已验收研究范围。任务聚焦于真实工程操作链中的物理运动反馈，不做“弹跳轮胎”的假动画。

从 R-18 的摆臂/拉杆/转向节/轮端姿态接入 R-17 的候选 `PartInstance/Frame/Joint/Constraint` 语义，形成可重复序列化的 `MotionFrame[]`：每帧都有 `instanceId`、位置、四元数、残差/求解状态、与工程修订匹配的 `runId`，不能依靠 GLB 子节点硬编码名称匹配。

必须检查：多行程循环连续且无旋转突变；摆臂长度、球铰闭合误差恒定在声明夹具容限；可见轮端与上下摆臂围绕正确铰点旋转、不通过缩放 Mesh；输入无物理质量/轮胎真实接触时 `force=N/A` 而不是编造受力；参数/代际/Frame 变化时流标 `STALE/BLOCKED`；碰撞代理清楚标为演示近似，不宣布真实复杂 CAD 干涉已验证。

交付：`src-experiments/mechanism-stream-v1/` 下纯 JS 模块、测试、静态连续姿态数据与可供现有 5173 消费的只读样例文件，`docs/research/R-23-motion-stream.md`、本人的 R-23 回报。必要时用旧 V2 5173 内部静态资源检查，不新开常驻端口/导航；不直接改其他模型项目文件。

# R-33｜左前轮端 CAD 与运动配准验证

## 目标

用 C-01 的左前转向节局部基准和 R-28 的演示机构，判断两套模型能否用可追溯的刚性变换对应。此任务解决坐标和版本证据，独立于 R-32 静态演示绑定。

## 输入和边界

- 输入 C-01 清单和 `PART-20-016` 安装基准、R-28 演示流、R-27 快照和 R-26 身份条件。协调 Codex CAD 提供参数及特征语义。锥孔入口、球心、轮轴和轮心分别核对，记录各自的物理含义。
- 可写隔离实验目录 `src-experiments/wheel-end-frame-registration-v1/` 和本工作位回报。保留原 C-01 资产、R-27、R-28 和主工作台文件。按现有定义保留轮毂 `ROLE_MARKER`、外拉杆 `REQUIRED_BUT_DEFERRED`。

## 交付与验收

1. 给出源与目标 Frame、轴向和单位，记录原始基准来源、快照和位姿运行标识、修订、哈希、变型和实例身份。用能唯一确定刚体关系的同物理基准求配准。验证旋转手性、位置和角度残差，并说明阈值依据。
2. 已有数据足以配准时，提交可复跑的局部到目标变换、至少一个独立校核及适用范围。数据不足时，提交具体缺失的点、轴或偏移，说明归属，并用机器断言证明应拒绝绑定。任何已解结果仍为 `DEMO_ASSUMPTION`。
3. 用可复跑的负例检查镜像、毫米与米混用、错版本与无法确定唯一刚体变换。缺失或不匹配时保持 `playbackAllowed: false`。向 DeepSeek、Codex CAD 和总控交接结果，父卡标 `submitted`。

# R-08｜把已验证的 CAD 流水线变成可靠的零件构建与质量门禁（Gemini Flash）

**背景**：R-03 的 build123d→Blender→GLB 多零件隔离实验已复跑成功：冷启动、缓存复用、制动盘单件增量更新、独立节点与 extras、Frame 基础测试均通过。但我们距离真正可扩展的精细零件库，仍缺一致的输入校验、数据来源标记、可复现输出、异常中断恢复与大规模性能预算。

**目标**：让后续 AI 只要给出符合约束的零件任务（尺寸、身份、安装接口、来源、允许的视觉简化），就能以可复现方式产出可靠的 STEP/GLB/资产清单，并明确地拒绝尺寸、装配、身份或来源不可信的输入。**不得把演示样例替代真实制造标准**。

**要达到的结果**：一份可执行的“资产质量门禁”方案及少量隔离原型，至少覆盖版本指纹与缓存失效、几何/元数据同步、mm→m 的刚体变换、失败恢复与错误说明、材料和 LOD 分层/性能。评估 R-03 现有机制还有哪些伪通过（例如只检查 GLB 节点存在而未查装配干涉）。结合 Qwen4 R-06 未来真实几何来源要求，但**不等待其把全部零件找齐**，可先用显式标记的演示数据研究流程。

# R-09｜为悬架实现可独立运行的约束求解与错误检测原型（Grok）

**背景**：R-04 已通过研究验证，使用演示硬点与 21 条约束测试分析了双叉臂、麦弗逊的运动关系，证明当前浏览器演示的摆臂长度缩放只是动画，不是工程装配。下一步应从研究报告升级到小型、可复用的运动学模块，而不是立刻改造旧汽车。

**成功目标**：建立**隔离的机械关节/硬点/行程求解器原型**，能输入明确标注来源等级的局部装配硬点、杆长和关节约束，输出轮心姿态、外倾/前束变化、减振器和半轴几何状态，并在行程不收敛、杆件长度冲突、关节极限、运动副错误时明确拒绝。优先证明“几何约束真实成立”，不声称整车动力学或冰雪摩擦真实性。

**验证重点**：不同参数/拓扑是否导致真实可检测的约束失败，单位/坐标是否能和 DeepSeek 的 Frame 提案及 Qwen4 的平台变型规则对接；真实硬点缺失时一律标 DEMO_ASSUMPTION。对多连杆或麦弗逊能做到什么程度由你调查后决定，复杂度与成本应在报告中解释。

**交付**：建议隔离目录 `src-experiments/kinematics/**` 或 `cad/experiments/kinematics_v1/**`（只能新建，不覆盖现有 `src/`）；`docs/research/R-09-kinematics-prototype.md`；实际验证数据、可复跑命令和个人报告 `agent-workspace/agents/grok/reports/R-09.md`。

**边界**：不是改动生产车辆的物理引擎，不直接接入 `vehicleWorld.js`，不伪造真实材料、轴荷、惯量或轮胎参数。不冻结共享 Schema，跨模型问题写 `agent-workspace/shared/messages/`，由总控裁决。**研究路线、方案和子任务完全由你自主决定**。验收必须有可复算的正例、负例和真实输出，完成后标 `submitted`。

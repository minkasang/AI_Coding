# C-05｜左前转向外端演示接口

基于 C-01 转向节、C-02 主轴、C-03 上下球心与 C-04 轮心，独立建一套有装配关系的转向臂外端安装特征及匹配球头。目的是为下一版演示夹具提供可从实际 STEP 复算的外球心。该设计使用 `DEMO_ASSUMPTION`。

1. 使用隔离的演示转向节衍生件或明确的演示接口件，交付 STEP、参数、生成入口及可复验的装入/落座检查。说明选定的连接方式和每个未知项，实测两件接触或间隙，并检查与当前转向节、上下球头和轮辋参考包的重叠。
2. 单列安装特征局部 Frame、局部及工装根外球心、单位、手性、输入摘要与拟议输出身份。做独立回读和至少一个尺寸或位置变体，验证改变只传播到相应基准。保留原外拉杆端实例的延期状态，样件用实验 ID。与千问 R-42、Grok 和 DeepSeek 文件交接。
3. 只写 `cad/experiments/wheel-end-steering-datum-v1/`、本人回报和公共交接。C-01 到 C-04 已发布件、R-27/R-28 与主工作台保持只读。当前输出保留播放关闭。

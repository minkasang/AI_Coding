# R-35｜验证 C-01 轮端视觉基线

## 目标

将 R-30 在旧轮端上验证的 PBR 单变量对照用在新的 C-01 GLB。判断轴承内外圈、轮毂、转向节和五颗螺柱能否在整体和局部观察中清晰区分，为后续主工作台静态接入提供视觉基准。

## 输入和边界

- 使用 C-01 已验收 GLB、清单与 R-30 的现有验证逻辑。若包缺失，按 C-01 文档重建。至少选择一组全装配和一组能辨认内外圈或安装关系的局部机位。局部观察可用适合该资产的隔离或剖切状态。
- 变更限 `viewer/experiments/wheel-end-visual-baseline-v1/` 和个人回报。主工作台、原 CAD 资产和现有 R-30 实验文件作为只读输入。使用现有服务或离线测试入口。
- 固定机位、灯光、曝光、可见性和网格，仅对照现有材质覆盖与 GLB 原生 `metalness` / `roughness`。保留 CAD 层级和局部变换。材料属于演示假设，报告注明使用的渲染后端。

## 交付和验收

1. 提供可复跑命令、至少两组同机位 A/B 截图，记录对应包 ID、GLB 哈希、可见零件和可核查的图像指标。指出哪些零件更好或更难区分，并说明适合沿用或暂缓哪种材质行为。
2. 验证 A/B 保持同一选择目标和装配位置，记录绘制调用数和网格量。证据使用软件渲染时，如实报告可比较的图像和绘制统计。
3. 提供一份给 Composer 的接入验收说明和截图位置，评估结论以孤立实验为准。待独立验收后再讨论主工作台应用。

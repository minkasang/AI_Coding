# C-04｜建立左前轮端演示轮心基准

## 目标

从 C-01、C-02 的轮毂车轮安装面和主轴，在独立 CAD 演示中定义轮辋的中心平面与主轴交点。把缺失的轴向偏移变成一个有几何和显式假设支撑的可复算输入，供同源演示夹具后续使用。

## 交付与验收

1. 编写参数化的简化轮辋基准件，至少表达两个对称参考截面和轮毂安装面。交付独立 STEP、参数及名义轮圈偏移的定义、方向和出处。无真实资料的尺寸用 `DEMO_ASSUMPTION`，资产使用实验标识。
2. 实际回读 STEP，独立从两个参考截面及主轴求轮心，核对安装面到轮心的有符号偏移。至少实测一个不同偏移的变体，校核毫米到米、轴向符号和手性。输出可机读的源哈希、Frame、点和轴。球心继承 C-03，外拉杆和整车运动保持原有阻断。
3. 只写 `cad/experiments/wheel-end-wheel-center-demo-v1/`、个人回报和交接消息。C-01/C-02/C-03 发布件、R-27/R-28 和主工作台作为只读输入。把复算方法与适用范围交给 Grok R-38 和 DeepSeek R-39。

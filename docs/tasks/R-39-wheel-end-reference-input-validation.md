# R-39｜轮端参考输入身份和修订检查

利用 C-02 机读基准、C-03 发布清单和 R-27 实际快照，对同源静态演示输入建立可重跑的读入检查，避免把不同 CAD 修订、角位或坐标系的文件拼成一套。

- 复用现有快照读取和哈希校验。交付独立检查入口、机读结果和 R-38 消费说明，包含已核对的转向节 PI、输入指纹、参考 Frame、单位、球心和来源。完整球铰候选保持候选，运动点保留其数据身份。
- 验证真包正例，以及错哈希、错快照修订、角位或球心互换、混单位、原 R-28 位姿误入、误把候选当生产实体等反例。待 C-04 时才允许录入其轮心数据。缺值与未知均显式呈现，当前输出保持禁止播放。
- 只写 `src-experiments/wheel-end-reference-input-v1/`、本人回报和公共交接。已验收的 R-32、R-27、C-02/C-03 和主页面作为只读输入。消费者接口的实现由本工作位自行选择。

# C-02｜轮端 CAD 基准接口

## 目标

为后续运动验证交付一份可由 Grok 直接读取并复算的 CAD 基准表。说明哪些点和轴已经由 CAD 实体给出，哪些物理对应还需要一个同源演示夹具或来源数据。

## 实施边界与验收

1. 从 C-01 已发布清单和已建几何提取转向节锥口、轴承端面与轮毂安装面，写出物理语义、单位、轴向、手性、Frame ID 和来源。区分 `assembly.json` 的安装锚点方向与 CAD 工装根坐标。用局部到工装根、工装根到 GLB 的独立算例交叉核对至少两个点和一个方向。
2. 给出供 Grok 消费的机读 JSON 与可复跑命令。复核 CAD 与现有运动夹具的主轴投影差，显式保留球心、车轮安装面到轮心及外拉杆接口的未知项。给出一个最小同源 DEMO 夹具的建议，列出 CAD 和运动工作位各自需要补的输入。待共同物理基准建立后再议可播放性。
3. 工作限 `cad/experiments/wheel-end-datum-interface-v1/`、本人报告和公共交接。已验收 C-01 包、R-27/R-28 与主页面作为只读输入。与 Grok 核对接口后提交。演示假设沿用 `DEMO_ASSUMPTION`。

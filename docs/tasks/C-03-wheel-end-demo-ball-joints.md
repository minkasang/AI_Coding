# C-03｜左前轮端同源球头演示基准

## 目标

用已经验收的 C-01 转向节和 C-02 安装基准，在隔离目录构建一对简化球头，使几何和未来演示运动夹具共享同一组实际生成的球心。现有 R-28 运动夹具仍由 R-33 单独核验。

## 交付与验收

1. 用 C-02 上下锥口的轴线和尺寸，以及公开记录的演示设计参数，生成上下两份独立 STEP 和可重复构建入口。至少记录装入方向、锥柄等效配合、落座和球心定义，尺寸来源保持 `DEMO_ASSUMPTION`。验证可回读、手性、锥孔轴与锥柄轴的对应，以及配合位置的相交或间隙。在样板范围内写明遗漏的零件特征。
2. 给出两颗球心在各自局部、C-01 工装根和米制坐标中的可复算数据，随文件记录 C-01/C-02 来源、单位、矩阵约定、版本或指纹。轮心与外拉杆关系仍按已有证据等级保留显式未知。与 Grok 确认该数据如何作为独立演示夹具输入。
3. R-27 中的 `PI-20-003-FL` 和 `PI-20-010-FL` 只作为候选关联，由千问 R-37 核对语义。把两份简化几何与完整球铰总成的边界写清。候选可用于工作位间的交接，主工作台保持现有 C-01 静态消费。
4. 只写 `cad/experiments/wheel-end-ball-joint-demo-v1/`、本人回报与交接消息。原 C-01、C-02、R-27、R-28 及主工作台作为只读输入。按原始产物、复跑命令和测试结果提交总控审核。

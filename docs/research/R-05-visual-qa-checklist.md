# R-05｜15 项视觉验收清单

> 版本 v1.0 · 2026-11-14 · HY4 · 配套 `docs/research/R-05-render-quality-report.md`
> 用途：作为**后续渲染优化任务的验收附件**与 A/B 每格的打分表。可直接打印勾选，也可作为自动截图比对判据。
> 证据类型：`人工` = 需人眼在固定帧上判断；`自动` = 可由脚本/数值断言；`人工+自动` = 两者结合。

## 使用规则

1. **固定镜头**：所有条目在 `http://127.0.0.1:5173/#mode=tire&tire=0`（或 `#mode=vehicle`）、窗口 **1600×1000**、同一 Chrome 版本与同一渲染后端下检查；**关闭「轮辋自转」**（`index.html:74`）或固定相位，否则帧不可比。
2. **记录参数**：每格记录 `toneMappingExposure`、`environmentIntensity`、相机 `position/target`、`devicePixelRatio`、GPU 型号、是否 SwiftShader、截图文件名与文件哈希。
3. **通过标准必须可证伪**：写成"看到 X 算通过 / 出现 Y 算失败"，不写"质感良好"这类无法判定的话。
4. **A/B 判定**：一次只改一类变量（见报告 §5.2），对下表逐项打 `PASS / FAIL / N/A`；任一改动至少要有两项 `FAIL→PASS` 且无新增 `FAIL`，才算该变量有效。
5. **本清单不预设性能阈值**：V15 只要求"数值被记录且可复现"，达标线由总控依据真实 GPU 实测另行裁定。

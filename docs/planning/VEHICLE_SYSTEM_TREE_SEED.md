## 每个系统的下钻模板

系统 → 子系统/总成 → 部件 → 零件/紧固件 → 安装接口（MountFrame） → 运动/能量/流体/信号接口（Interface） → 车型/参数适用规则（VariantRule） → 可靠性和验证等级（Evidence）。

**示例：轮端**
SYS-30 → 轮端总成 → 轮毂/轴承/法兰/车轮/制动盘/卡钳支架等（注意制动系统归 SYS-40，轮端总成可跨系统引用）→ 各安装面、螺栓孔及法兰轴向 → 与转向节/半轴/制动液/轮速传感接口 → 可选轮胎/轮辋规格与 PCD → CAD + GLB + 装配验证。

**示例：内燃机**
SYS-50 → 发动机 → 缸体/缸盖 → 活塞/连杆/曲轴、气门/凸轮轴/正时驱动、进排气/燃油/点火、润滑/冷却（冷却由 SYS-80 跨系统关联） → 曲轴与飞轮/变速器机械连接 → 质量/体积/运动链。默认先几何+正确运动关系；燃烧/传热精度要另行确定。

**示例：制动**
SYS-40 → 制动总成 → 踏板/助力/主缸、液压管线、轮端卡钳/制动盘（与 SYS-30 共用轮端装配位置）、驻车机构、传感器/控制器（与 SYS-90/140 联动） → 液压压力/卡钳夹紧力/热量/控制信号 → 工况验证。

## 缺口识别标签

- `COVERED`：在现有计划中出现且有明确下游交付与测试；
- `MENTIONED`：仅提到名称，但没有展开功能/接口/测试；
- `MISSING`：现有计划没有明确列出；
- `CONFLICT`：两个规范使用不同单位、名词、责任或接口；
- `UNKNOWN`：资料无法确认，或未来车型可能需要。

研究代理按**原总计划实际文本**判断，不能仅凭此种子把一个系统视为“已在总计划覆盖”。

## 第一版车型样例应保持可控

优先选择一套**示意型越野/通用底盘**来验证可拆解、可参数化和运动真实性，并说明是否非承载式、动力方案以及假设尺寸；不要默认越野底盘更换轿车外壳即可达到工程正确。第二套承载式/电动轿车平台应视作后续平台家族，用来检验复用边界。
